# Бот публикаций в Instagram

Публикует Reels и фото в `@salammotion` по очереди `queue.json`. Запускается сам каждый час через GitHub Actions
(`.github/workflows/social-post.yml`).

## Правила оформления роликов (от автора)

Применять к каждому ролику, в том числе в автоматическом монтаже:

- **Эффекты всегда мягкие**: тихо (не громче звука ролика), без резких верхов, с плавным хвостом.
- **Не перегружать**: звук только там, где у него есть смысл; без озвучки каждого движения, без ударов и райзеров по умолчанию.
- **Одна музыка за раз**: если у сгенерированного ролика свой звук, под ним ничего своего не играет.
- **Без синтезированного звука**: только файлы из пака автора (приватный репозиторий `artega909-del/salam-assets`).
- **Текст без дублей**: одна мысль на экран, не больше ~3 слов в секунду чтения.
- **Логотип и ссылка `salammotion.com` обязательно** (финальная карточка; в интерфейсе — шапкой).
- Всё важное — вне зон интерфейса Reels: сверху ниже 280 px, снизу выше 1560 px, правая колонка кнопок свободна.

## Секреты

Хранятся **только** в GitHub: Settings → Secrets and variables → Actions.

| Имя | Что это |
|---|---|
| `INSTAGRAM_ACCESS_TOKEN` | токен системного пользователя Meta (без срока действия) |
| `INSTAGRAM_ACCOUNT_ID` | ID Instagram-аккаунта из Business Settings |

Токен нельзя вставлять в файлы репозитория (сайт публичный), в чат и на скриншоты. Если он где-то засветился: Business Settings →
Системные пользователи → `salam-bot` → «Отозвать маркеры», затем создать новый.

## Как добавить пост

Отредактируйте `social-bot/queue.json`, добавив запись в `posts`:

```json
{
  "id": "salam-002",
  "brand": "salam",
  "platform": "instagram",
  "type": "REELS",
  "media": "assets/salam-002.mp4",
  "caption": "Текст подписи #хештег",
  "publish_at": "2026-12-03T09:00:00Z",
  "status": "scheduled"
}
```

- `type`: `REELS` (видео `.mp4`/`.mov`, лучше 9:16) или `IMAGE` (JPEG).
- `media`: путь к файлу внутри репозитория (например `assets/…`; файл должен быть загружен в репозиторий и опубликован
  на GitHub Pages) или готовая ссылка `https://…`.
- `publish_at`: время UTC (`Z` на конце). 09:00 по Ашхабаду (UTC+5) — это `04:00:00Z`.
- `status`: `draft` — черновик, бот не трогает; `scheduled` — опубликовать, когда наступит время.
- Подпись до 2200 символов, до 30 хештегов.
- `cover_ms` (необязательно, только для REELS): кадр-обложка, миллисекунды от начала видео, например `0` или `1500`.
- `repeat: true` (необязательно): разрешить пост с подписью, которая уже есть в последних 25 постах аккаунта.

Статусы, которые проставляет бот: `published` (с `media_id` и `permalink`), `failed` (причина в `error`),
`missed` (время прошло более 48 часов назад — назначьте новое и верните `scheduled`).
Бот не повторяет неудачные посты сам, чтобы не опубликовать дважды.
Защита от двойной публикации: перед публикацией бот сверяет подпись с последними 25 постами аккаунта. Если такой пост
уже есть (прошлый запуск опубликовал, но не успел сохранить статус), запись помечается `published` с пометкой в `note`.
Поэтому подписи разных постов должны отличаться (или ставьте `repeat: true`).

## Проверка

GitHub → Actions → «Instagram — публикация по очереди» → Run workflow:

- `check` — проверяет, что токен и аккаунт работают, ничего не публикует;
- `dry-run` — показывает, что вышло бы в эфир сейчас;
- `publish` — публикует то, что пора.

Локально без интернета: `node social-bot/test.mjs` (подменяет Instagram API).

## Важно знать

- Все файлы репозитория публичны на GitHub Pages, включая `queue.json` (подписи черновиков видны всем).
- Бот просыпается раз в час (в :17 по UTC), поэтому пост выходит в течение часа после `publish_at`; GitHub иногда задерживает расписание ещё на несколько минут.
- Расписание GitHub работает только на основной ветке (`main`). Бот коммитит обновлённые статусы очереди в `queue.json`.
- Если репозиторий 60 дней без активности, GitHub отключает расписание в публичных репозиториях; коммиты бота считаются активностью.
- Публикация через API ограничена Instagram (около 100 постов в сутки); бот публикует не больше 3 постов за запуск.
