Подключение TikTok к Salam Motion Bot

Бот загружает готовые ролики черновиками во «Входящие» TikTok. Публикует автор сам, в приложении TikTok.

Ключ не секретный и никуда не отправляется, кроме TikTok. Client secret здесь не нужен — он хранится только в GitHub Secrets.

Код получен. Он действует несколько минут:


    
    
    
      
  1. Откройте GitHub → Actions → «TikTok — подключение».
    2. 
      
  2. Нажмите «Run workflow», вставьте код в поле code, выберите аккаунт и запустите.
    3. 
      
  3. Через минуту бот напишет в журнале запуска: «TikTok подключён».
