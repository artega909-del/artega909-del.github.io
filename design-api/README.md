# Сервер генерации для визуализатора

> Этот сервер нужен только для автоматической платной генерации. Бесплатный способ работает без него: страница составляет запрос для любой нейросети с редактированием картинок, а готовый вариант загружается обратно в редактор.
> Бесплатного автоматического варианта, который уверенно перерисовывает комнату по фото, на момент проверки найти не удалось. У Google Gemini по свежим источникам генерация картинок через API платная, а у Cloudflare Workers AI есть бесплатные 10 000 «нейронов» в день, но модель для перерисовки комнаты по фото мы не нашли. Условия у провайдеров меняются, перед запуском проверьте их страницы.

Маленький сервер-посредник. Страница `/design/` отправляет ему фото, стиль и пожелания, он обращается к нейросети и возвращает варианты.
Ключ нейросети лежит только здесь, на странице его нет.

## Что понадобится

1. **Аккаунт Cloudflare** (бесплатного тарифа хватает): https://dash.cloudflare.com/sign-up
2. **Ключ OpenAI** с пополненным балансом: https://platform.openai.com/api-keys
   Для модели `gpt-image-1` OpenAI может попросить подтвердить организацию. Если при первом запуске придёт ошибка про доступ, начните с этого.
3. **Node.js** на компьютере: https://nodejs.org

## Запуск за 5 минут

В терминале, в папке `design-api`:

```bash
npx wrangler login                      # откроется браузер, войдите в Cloudflare
npx wrangler secret put OPENAI_API_KEY  # вставьте ключ OpenAI, когда попросит
npx wrangler deploy                     # в конце выведет адрес сервера
```

Адрес похож на `https://design-visualizer-api.ваше-имя.workers.dev`. Проверьте, что он живой: откройте `адрес/health`, должно быть `{"ok":true}`.

Дальше откройте страницу визуализатора, блок «Нарисовать вариант (ИИ)» → «Настройки сервера генерации» и вставьте адрес.
Чтобы адрес был подставлен для всех сразу, впишите его в `design/index.html` в константу `GEN_DEFAULT_URL`.

Генерация работает на самом сайте (`artega909-del.github.io/design/`) и при открытии файла с компьютера. В закрытой ссылке на claude.ai она недоступна: там браузер запрещает страницам обращаться к посторонним серверам.

## Деньги и защита

- **Цена.** Платите OpenAI за каждую картинку. Точные цены смотрите у них на странице тарифов. Стоимость растёт с качеством: `IMAGE_QUALITY` в `wrangler.toml` (`low`, `medium`, `high`).
- **Лимит.** Задайте месячный лимит расходов в личном кабинете OpenAI. Это самая надёжная защита от неожиданных счетов.
- **Число вариантов.** `MAX_VARIANTS` ограничивает, сколько картинок можно заказать одним запросом.
- **Кто может обращаться.** `ALLOWED_ORIGINS` в `wrangler.toml`: только эти сайты смогут вызывать сервер из браузера. Сменится домен, впишите новый.
- **Ключи доступа для клиентов.** Без них сервером может пользоваться любой, кто знает адрес и открыл вашу страницу. Чтобы закрыть: `npx wrangler secret put APP_TOKENS` и список ключей через запятую (`ключ1,ключ2`). Клиент вводит свой ключ в настройках. Это основа для будущей подписки: выдали ключ, оплатили, ключ работает. Отозвать клиента значит убрать его ключ из списка.

## Другая нейросеть

Весь вызов нейросети находится в одном месте, в `worker.js` рядом со строкой `images/edits`. Чтобы взять другого провайдера (Stability, Replicate, Google и т. п.), замените этот запрос и разбор ответа. Страница и остальные проверки менять не нужно.

## Проверка без нейросети

```bash
node design-api/test.mjs
```

Запускает сервер с подставной нейросетью и проверяет лимиты, защиту, ошибки и то, что ключ не попадает в ответ.
